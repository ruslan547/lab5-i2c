# lab5-i2c — BMP180 по шине I2C на STM32F401RE

Лабораторная работа №5 по курсу «Аппаратно-программное обеспечение БПЛА».
Программная реализация работы с датчиком давления **BMP180** по интерфейсу
**I2C** на микроконтроллере **STM32F401RE** (регистровый доступ, CMSIS).

## Вариант

| Параметр | Значение |
|---|---|
| Частота шины | 200 кГц (Fast mode) |
| Датчик | BMP180 (адрес 0x77) |
| Модуль | I2C3 |
| SCL | PA8 (AF4) |
| SDA | PC9 (AF4) |

## Подключение индикатора LM016L

| Сигнал | Вывод МК |
|---|---|
| RS | PB2 |
| E | PB3 |
| D4…D7 | PB4…PB7 |
| RW | общий провод |

## Структура

| Путь | Назначение |
|---|---|
| `Src/main.c` | Инициализация I2C3, обмен с BMP180, вывод на ЖКИ |
| `Src/clock.c` | HSI 16 МГц → PLL → SYSCLK 84 МГц, APB1 = 42 МГц |
| `Src/delay.c` | Задержки на SysTick без прерываний |
| `Src/lcd1602.c` | Драйвер HD44780 (LM016L) в 4-проводном режиме |
| `firmware/lab5-i2c.hex` | Готовая прошивка для Proteus |

## Расчёт параметров I2C

При `PCLK1 = 42 МГц`, Fast mode, скважность 2:1:

```
CR2.FREQ = 42
CCR      = 42·10⁶ / (3 · 200·10³) = 70 (0x46)
TRISE    = 42 · 300 / 1000 + 1    = 13
```

## Сборка

Открыть проект в **STM32CubeIDE** → `Project → Build Project` (⌘B / Ctrl+B).

Генерация Intel HEX включена в конфигурациях Debug и Release, поэтому после
каждой успешной сборки автоматически выполняется

```
arm-none-eabi-objcopy -O ihex lab5-i2c.elf lab5-i2c.hex
```

и прошивка появляется в каталоге `Debug/` (либо `Release/`).

> Если каталог сборки остался от предыдущей версии проекта и новые файлы
> не попадают в сборку — выполнить `Project → Clean…`, чтобы среда заново
> сформировала `makefile` и `subdir.mk`.

## Моделирование в Proteus

В свойствах STM32F401RE указать `firmware/lab5-i2c.hex` и частоту кварца 16 МГц.
